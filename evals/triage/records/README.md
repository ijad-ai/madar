# Labeled failures

Real, anonymized, double-labeled failures go here as `tri-NNNN.json`, one per file. Every file is validated in CI against `../schema.ts` and the leak guard.

**Status: 0 of 10** for the Phase 0 target, **0 of 50** for the Phase 4 gate. These come from your team's CI history (conflict C-002 in `docs/decisions.md`). Synthetic examples live in `../fixtures/` and never count.
